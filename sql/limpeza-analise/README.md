Limpeza SQL
Esta pasta contém as limpezas e alterações utilizadas na camada incial do projeto IMUNE.

Arquivos
remocao_colunas.sql: remoção de colunas que não são interessantes para análise.
coluna_racacor.sql: criação da coluna referência que adiciona descrição para os códigos de raça/cor do DataSUS.
coluna_hospitais.sql: criação da coluna referência que adiciona o nome para os CNPJs dos hospitais disponibilizados pelo DataSUS.
